01

Satellite Recon

Easy

RF / Framing · always unlocked · auto-completes

The satellite broadcasts the same short loop of frames, over and over, on a fixed downlink. Every frame is wrapped in the same envelope - same delimiter, same address fields, the same couple of fixed control bytes. This level is just learning what that envelope looks like and reading its constant fields back to the badge. Nothing is transmitted; you only listen.

Tool

The badge’s own capture screen + a serial terminal on your laptop. A notebook helps.

Hint
  1. This is a standard framed radio protocol, not something proprietary - look for a fixed start/end delimiter byte that opens and closes every frame.
  2. Between the two delimiters sit fixed-length address fields, then a one-byte control field and a one-byte protocol ID. Those last two never change from frame to frame.
  3. Capture several frames and line them up: the bytes that are identical every time are the framing values the screen is asking for. One short command code is sitting in readable ASCII inside one of the frames, too - you do not have to decode anything for it.

02

Telemetry Intelligence

Easy

RF / Address decoding · requires Level 1 · auto-completes

The SRC address from Level 1 is not a random code - it encodes the satellite’s call-sign and a small ID, each character nudged one step off by a simple per-byte transform. Undo the transform and the identity falls out. This level wants that call-sign, that ID, and the command code you already read in the clear.

Tool

Any calculator or one line of Python to shift bytes. The same captured frame as Level 1.

Hint
  1. Standard radio addressing does not store letters directly - each is shifted by one bit position before being sent.
  2. Take the 7-byte SOURCE address, turn each byte into a number: they sit suspiciously close to, but not exactly on, familiar letter codes. Undo the shift on the first six bytes to get the call-sign; the seventh byte holds a small ID the same way.
  3. Combine the decoded call-sign and ID with the command code already sitting in plain text elsewhere in the loop - the one you found in Level 1.

03

Flight Computer

Medium

Firmware reverse engineering · requires Level 2 · auto-completes

Nothing in the radio chatter points here. Instead the satellite’s own firmware is genuinely open-source, and this screen will hand it to you over USB. Somewhere in that source is a diagnostic request format with a checksum you are meant to compute, not copy. Get it right and the satellite replies with a seed you will need next level.

Tool

The helper script download_firmware_source.py (Python 3 + pyserial), the badge’s “Download Open-Source Firmware” prompt, and a text editor/grep.

Hint
  1. There is no telemetry or hardware clue for this one - use the “Download Open-Source Firmware” prompt to pull the source onto your computer.
  2. Find the check it runs for a request shaped like FCDIAG:<opcode>:<args>:<checksum>. It names one exact opcode and two exact argument bytes - read them from the source, do not guess.
  3. The checksum is (opcode + sum of args) & 0xFF, written as two uppercase hex characters. Work the formula, send the request core, and the satellite replies with the seed string you will need verbatim for Level 4.

04

Establishing the Uplink

Hard

RF / Protocol implementation · requires Level 3 · auto-completes

Now you transmit back, and the satellite has to believe you. The uplink pass-phrase is not on the screen and not in the firmware - it is physically inscribed on the badge’s own circuit board, written in the same style as every flag. Read your own hardware, translate it, and transmit it.

Tool

Your eyes on the PCB, the same flag-style translation you have used all along, and the badge uplink prompt.

Hint
  1. There is no telemetry or hardware clue in the air for this one - the badge you are holding is itself part of the puzzle. Look at it, not just the screen.
  2. There is text printed directly on the PCB. It is not plain English as printed - it is in the same lowercase, underscore-separated style as every flag you have recovered so far.
  3. Translate the inscription the same way to get a short lowercase phrase with no spaces, then enter that exact phrase at the prompt. The badge handles the transmit and the handshake.

05

Operation Vanguard

Medium

File recovery · requires Level 4 · manual flag submission

No codes to crack. The satellite hands you a file; your job is to realise it is a container, find the ordinary free tool that opens it, and look at what is inside. The final flag is in there in plain sight - and this is the one level whose flag you type in by hand.

Tool

The helper script download.py (Python 3 + pyserial), gunzip, a hex viewer, and anything that can show a raw grayscale image (e.g. Python + Pillow).

Hint
  1. The downloaded payload.bin is not a standalone image you can double-click - check what format it actually is first.
  2. Look at its first two bytes in a hex viewer. 1F 8B is the gzip magic number - decompress it. What comes out has no header of its own; its exact length tells you the image is square.
  3. 16384 bytes = 128×128 8-bit grayscale pixels, no header. Load it as a raw image at that size/mode and view it - the flag is written on the picture. Type it into Submit Flag.
